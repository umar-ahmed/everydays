# everydays

A home for daily 30-minute interactive toys, one per numbered day. Each day is its own page (`/001/`, `/002/`, …) and the root `/` lists them all.

Built with Vite + React + TypeScript, [Motion](https://motion.dev) (`motion/react`), [DialKit](https://github.com/joshpuckett/dialkit) for live tuning panels, and Tailwind. Day 006 synthesizes its sound with Web Audio and an AudioWorklet. Days 002, 003 and 004 use [three.js](https://threejs.org) with its WebGPU renderer and TSL compute shaders.

## Run it

The toolchain is [Vite+](https://viteplus.dev) (`vp`): Vite on Rolldown, Vitest, Oxlint, Oxfmt and Vite Task in one package. Use Node `^22.18.0 || ^24.11.0 || >=26` (`.nvmrc` pins 22.23.4). The `vp` binary comes with the `vite-plus` dev dependency, so either install it globally (`curl -fsSL https://vite.plus | bash`) or prefix the commands below with `npx`.

```bash
vp install            # install dependencies (npm under the hood)
vp dev                # http://localhost:43117
vp check              # format check (Oxfmt), lint (Oxlint) and type check, type-aware
vp check --fix        # ...and apply formatting and autofixes
vp test               # unit tests (Vitest, src/**/*.test.ts)
vp build              # static site in dist/ (index, /001/, /002/)
vp preview            # serve dist/ at http://localhost:43118
vp run check:gpu      # day 002 WebGPU checks in headless Chromium (cached, see below)
npm run og            # regenerate the Open Graph cards (see below)
```

`vp lint` and `vp fmt` run the linter and formatter on their own. Lint and format settings live in the `lint` and `fmt` blocks of `vite.config.ts`.

`vp run check:gpu` runs the real day 002 bubble-map generator on SwiftShader WebGPU in headless Chromium and checks every sheet, layout and camera invariant across five viewports. It then runs the real cloth sim: presses one bubble (center, edge and corner, with and without an edge margin, on desktop and phone sheets) and asserts that nothing else pops, kinetic energy dies down and the sheet stays flat. `vp run check:gpu:sheets` runs the sheet half (CI runs only this one); `vp run check:stability` runs the pop-stability half, which is opt-in and never runs in CI (about 10 minutes locally, 30 on CI). It needs Playwright's Chromium (`vp exec playwright install --only-shell chromium`) and takes several minutes. It is a cached Vite Task: it replays instantly until something under `src/days/002/`, `scripts/check-002/`, `src/days.ts`, `vite.config.ts` or the lockfile changes. `vp cache clean` forces a rerun.

## Adding a day

1. Append an entry to `src/days.ts` (slug, title, one-line concept, date).
2. Copy `001/index.html` to `NNN/index.html` and point its script at `src/days/NNN/main.tsx`.
3. Build the toy in `src/days/NNN/`.
4. Add a 1200x630 `public/NNN/og.png`.

The Vite config reads `src/days.ts` to register each page as a build input and to fill in the page's title and Open Graph tags. The build fails if a listed day has no `index.html`.

## Open Graph and the base URL

Every page gets `og:title`, `og:description`, `og:image`, `og:url` and `twitter:card=summary_large_image`, injected at build time in place of the `<!-- head:meta -->` comment. The absolute URLs use the first base URL found:

1. `SITE_URL` or `VITE_SITE_URL` (from the environment or a `.env` file), e.g. `SITE_URL=https://everydays.dev npm run build`
2. On Vercel, `VERCEL_PROJECT_PRODUCTION_URL` (or `VERCEL_URL`), prefixed with `https://`
3. Otherwise `http://localhost:43118`

On Vercel, set `SITE_URL` in the project's environment variables once you have the domain. Until then, the Vercel production URL is used automatically.

`npm run og` regenerates `public/og.png` (the index card), `public/001/og.png` and `public/002/og.png`. Run it while `vp dev` is running (set `OG_BASE` to the dev URL including any base path, e.g. `http://localhost:43117/everydays`). Day 001 is driven on a fake clock so its screenshot comes out the same every run; `OG_FRAME` picks a different frame of the sweep. Day 002 presses a few bubbles in the real WebGPU sim (headless Chromium with SwiftShader, so it takes a few minutes). `OG_ONLY=index,002` rebuilds only the listed cards.

If the base URL has a path (e.g. `https://umar-ahmed.github.io/everydays`), that path also becomes Vite's `base`, so assets and links are served from `/everydays/`. In code, build in-site links from `import.meta.env.BASE_URL` rather than a leading `/`.

## Deploying

The site is live at <https://umar-ahmed.github.io/everydays/>. `.github/workflows/pages.yml` runs `vp check`, `vp test` and the GPU sheet checks, then builds with `vp build` and deploys to GitHub Pages on every push to `main`, with `SITE_URL` set to the Pages URL.

`vercel.json` sets the build to `npm run build` (which runs `vp build`) with output in `dist/`. Any static host that serves `dist/` works.
